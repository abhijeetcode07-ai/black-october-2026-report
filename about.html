About the website

One week.
Seven signals.

Black October 2026 is an incident atlas that makes a dense week of cybersecurity news easier to follow.

What you will find here

A clear path from the first alert to the final fix.

The homepage gives you the complete chronological timeline from 17–22 October 2026. Use the category filters, severity filter and search box to narrow the view, then open any card for the full report.

Each incident page brings the important pieces together: quick facts, what happened, a dated sequence, attack mechanics, impact, fixes, lessons, a glossary and source links.

A small technical note

Built as a static, browser-first project.

The site uses XML as its content layer and vanilla JavaScript to render the pages. The AI-suggested tags and related incidents are lightweight, browser-only text analysis: weighted keywords, TF-IDF and cosine similarity. There is no login, database, backend or external AI key.

Educational project

The site is designed for learning web technologies and cybersecurity reporting. Follow the linked sources for the latest authoritative information.
